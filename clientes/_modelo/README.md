# Cliente Modelo

Este diretório serve como base para criar novos clientes.

A ideia é evitar copiar diretamente o 2Vales ou a Gaivotto Studio.

## O que editar em novo cliente

- config.json
- ana/Prompts/Identidade/Identidade.txt
- ana/Prompts/Identidade/Personalidade.txt
- ana/Prompts/Negocio/Informacoes.txt
- ana/Prompts/Operacao/Regras.txt
- Arquivos necessários, como PDF, cardápio, imagens ou documentos

## O que vem do core universal

- logs mensais
- controle de pausa
- handoff humano
- horário Brasil
- estrutura técnica reutilizável

## Regra

Código técnico deve ir para /core.

Informação específica do cliente deve ficar dentro da pasta do cliente.
